# ADR-0002: Изолированный локальный ИИ-контур (On-Prem LLM) и разделение IT/OT по ISA/IEC 62443

## Status

Accepted (2026-11-18)

## Context

Чертежи заказчиков (STEP/PDF), управляющие программы станков ЧПУ (G-code), коммерческие прайс-листы поставщиков металлопроката и маржинальность заказов составляют коммерческую тайну предприятия и защищены соглашениями NDA. Передача этих данных во внешние облачные LLM API запрещена требованиями информационной безопасности промышленных заказчиков. Кроме того, прямое подключение ИИ-агентов к стойкам ЧПУ создаёт физические риски повреждения оборудования.

## Decision

1. **Классификация и маршрутизация данных** (источник истины: `specs/security/on_prem_llm_architecture.md`, `docs/contracts/data_classification.md`):
   - **ОТКРЫТЫЕ данные** (ГОСТы, марочники сталей, табличные режимы резания): допускается обработка в любом контуре.
   - **ЧУВСТВИТЕЛЬНЫЕ данные** (тексты входящих заявок без чертежей, прайсы поставщиков, наименования клиентов): обработка строго внутри локального периметра завода через On-Prem LLM (`Qwen2.5-7B-Instruct` на `llama.cpp` / `Ollama`).
   - **КОНФИДЕНЦИАЛЬНЫЕ данные** (чертежи STEP/PDF, G-code, расчёт себестоимости, P&L и выгрузки 1С): передача в любые LLM запрещена; обработка исключительно детерминированным Python-ядром (`engine/`).
2. **Изоляция IT/OT по стандарту ISA/IEC 62443**:
   - Сбор телеметрии со станков ЧПУ (OPC UA / MTConnect) осуществляется строго в режиме `Read-Only` через изолированный Edge Gateway.
   - Прямая запись управляющих программ или параметров в стойки ЧПУ со стороны ИИ-контура физически и программно заблокирована.

## Consequences

- **Позитивные**: Полное соблюдение NDA с заказчиками из машиностроительного и нефтегазового секторов; отсутствие риска галлюцинаций LLM в финансовых расчётах и расписании станков.
- **Ограничения**: Требуется локальный сервер (GPU RTX 3060/4060 12GB+ или Mac Mini M2/M4 Pro) в локальной сети завода для парсинга неструктурированных текстовых заявок.

## Rollback

В случае отказа от локальной LLM парсинг входящих заявок переводится на ручной ввод через шаблоны Obsidian (`06_Шаблоны/Шаблон_Заказа.md`) при сохранении работы всего расчётного ядра `engine/`.

## Validation

- Аудит сетевой конфигурации локального инференса (`127.0.0.1`, отсутствие внешних API-ключей в окружении `engine/`).
- Проверка отсутствия сетевых вызовов в модулях `engine/*.py`.
