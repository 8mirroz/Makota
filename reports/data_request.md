# Запрос данных у владельца — приложение к письму

> Цель: получить минимальный набор реальных данных для двух прототипов (MVP-1 «Закупки и тендеры», MVP-2 «Цифровой бегунок»).
> Конфиденциальность: данные обрабатываются локально, не передаются в облачные сервисы; NDA по запросу.

## Приоритет 1 — без этого пилот не стартует

| # | Данные | Формат | Объём | Для чего |
|---|--------|--------|-------|----------|
| 1 | Выгрузка тендерной системы: дата, номенклатура, марка стали / профиль / диаметр, объём (кг/шт), цена участия, результат (выигрыш/проигрыш), цена победителя если известна | Excel / CSV (как отдаёт система) | Вся история или последние 12 мес | MVP-1: пулинг по маркам, разбор проигранных тендеров |
| 2 | Действующие заказы для пилота «бегунка»: состав, срок, текущий этап, ответственный менеджер | Карточки / созвон / таблица | 3–5 заказов | MVP-2: контрольные точки и эскалация |
| 3 | Контакты: снабженец, диспетчер цеха, технолог; день визита на производство | Встреча / звонок | 1 день | Оба MVP: нормативы SLA, живые интервью |

## Приоритет 2 — нужно в первые 2 недели

| # | Данные | Формат | Объём | Для чего |
|---|--------|--------|-------|----------|
| 4 | Исторические заказы: состав, спецификации, план/факт себестоимости (материал, машинное время, инструмент, накладные), даты по этапам (принят → закупка → цех → отгрузка) | Excel / CSV / выгрузка 1С | 30–50 заказов | MVP-1: карта потерь; MVP-2: реальные нормативы времени переходов |
| 5 | Прайсы поставщиков металлопроката + условия доставки (минимальная партия, стоимость рейса по тоннажу) | Excel / PDF / фото прайсов | Текущие, 3–5 основных поставщиков | MVP-1: расчёт экономии оптовых пулов и логистики |

## Приоритет 3 — для второй фазы (Cost Engineer)

| # | Данные | Формат | Объём | Для чего |
|---|--------|--------|-------|----------|
| 6 | Шаблон калькуляции себестоимости (как считаете сейчас) + ставки станко-часа по группам оборудования | Excel / MD | Текущий | Cost Engineer: калибровка формулы под ваше производство |
| 7 | Реестр режущего инструмента: что используется, нормативная стойкость, цены пластин | Любой | По возможности | Cost Engineer: учёт износа инструмента в с/с |
| 8 | Типовые чертежи / спецификации деталей (обезличенные, если нужно) | PDF / STEP / Excel | 5–10 примеров | Cost Engineer: извлечение геометрии, маршруты обработки |

## Формат передачи

- Файлы: любым удобным способом (почта, мессенджер, флешка при визите).
- Если выгрузка из 1С/тендерной системы требует настройки — подскажу, какие поля нужны; достаточно скриншота формы выгрузки.
- Чувствительные поля (имена клиентов, контакты) можно обезличить — для расчётов они не нужны.

## Минимум для старта

Пункты **1 + 2 + 3** запускают оба прототипа. Остальное досылаем по ходу.
