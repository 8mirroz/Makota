# Решение: Устранение дробления и вибраций при растачивании ЧПУ

## 🔍 Симптомы
- Характерный металлический звон/свист на оборотах выше 800 об/мин.
- На обработанной поверхности видна волнистость (огранка) или следы хаотичного дробления.
- Быстрый выкрашивание вершинки пластины (CCMT / WNMG).

## 🛠️ Чек-лист устранения (от простого к сложному)
1. **Проверить вылет оправки**:
   - Стандартная стальная оправка: жесткость сохраняется только до $L/D \le 4$.
   - При вылете $L/D = 5–7$: использовать антивибрационную оправку с тяжелосплавным или твердосплавным стеблем.
2. **Уменьшить радиус при вершине пластины ($r_\varepsilon$)**:
   - Заменить пластину с $r_\varepsilon = 0.8$ мм на $r_\varepsilon = 0.4$ мм или $0.2$ мм. Это снижает радиальную составляющую силы резания $F_r$, которая и отжимает резец.
3. **Изменить угол в плане ($\kappa_r$)**:
   - Использовать оправки с углом $\kappa_r = 90^\circ$ (пластины CCMT/DCMT) вместо $\kappa_r = 75^\circ$.
4. **Скорректировать режимы резания**:
   - Снизить скорость резания $V_c$ на 20–30%.
   - Увеличить подачу $f_n$ (увеличивает демпфирование стружкой).
   - Глубина резания $a_p$ должна быть строго больше радиуса вершины ($a_p > r_\varepsilon$).
